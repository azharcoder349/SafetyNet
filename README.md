🛡️ SafetyNet – AI Safety Copilot

SafetyNet is an AI-powered personal safety application that helps users handle potentially risky situations and stay connected with trusted contacts.

🌐 Live Demo

🔗 [Live Deployment: "YOUR_LIVE_DEPLOYMENT_LINK"](https://safety-net-mauve.vercel.app/)

✨ Features

- 🤖 AI Safety Copilot – Describe your situation and get safety guidance.
- ⏱️ Safety Timer – Set a check-in timer for your safety.
- 👥 Trusted Contacts – Add trusted people for emergency situations.
- 🛡️ Simple & User-Friendly Interface

🛠️ Built With

- Next.js
- TypeScript
- React
- Tailwind CSS
- AI

🎯 Purpose

SafetyNet is designed to provide quick and simple safety assistance when someone is travelling alone, walking at night, or facing an uncertain situation.

🚀 Run Locally

npm install
npm run dev

⚠️ Disclaimer

SafetyNet is a safety-support tool and should not replace emergency services.
